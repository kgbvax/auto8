# internal/tx

This directory holds all TX control code of auto8.

TX control is code that can make WSJT-X or MSHV transmit.
TX control is also code that decides the time at which auto8 can ask for a transmission.
The arm logic and the presence logic are examples.

Put all TX control code in this directory. Do not put it in other directories.

The operator owns this directory as code owner.
The operator must approve each change in this directory. Then the change can merge.
